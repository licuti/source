Update order
put
https://crm.pancake.vn/api/workspaces/{workspace_id}/orders/{id}
Update an existing order by ID. The payload must be wrapped in an order object and follows the same shape as create. Only provided fields are changed.

Line items in order.items are reconciled: items with an existing item_id are updated, items without one are inserted, and existing items omitted from the list are removed. To soft-delete an order, send order.is_removed = true.
