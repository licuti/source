Create product
post
https://crm.pancake.vn/api/workspaces/{workspace_id}/products
Create a new product in the workspace.

type defaults to product when omitted. Type-specific fields are stripped server-side: service drops remain_quantity, service_package drops remain_quantity and duration, and only service_package keeps service_package_product. Provide variations to create product variations in the same request; provide service_package_product (for type: service_package) to link component services with their quantities.

Request
API key is used to authenticate users when accessing the CRM API.

You can generate an API key in Pancake CRM: Settings → Tools.

The API key may be automatically disabled after a period of inactivity.

How to get api key?
An API key is a token that you provide when making API calls. Include the token in a query parameter called api_key.

Example: ?api_key=123
