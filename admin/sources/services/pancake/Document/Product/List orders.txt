List orders
get
https://crm.pancake.vn/api/workspaces/{workspace_id}/orders
List orders in a workspace, most recent first.

Results are paginated using page / page_size (offset-based) and can be narrowed with search (matches order code OD..., custom ID, or billing phone number) and a structured filter. Only orders the current API key is allowed to see are returned.
