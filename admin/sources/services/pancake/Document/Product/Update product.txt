Update product
put
https://crm.pancake.vn/api/workspaces/{workspace_id}/products/{id}
Update an existing product. The body must be wrapped in a data object and data.id must match the product to update (the same ID as in the URL).

Passing variations replaces the product's variations: existing variations whose custom_id is not in the new list are deleted, matches are updated, and new entries are inserted. Passing service_package_product (only valid for type: service_package) fully replaces the linked service list.

Request
API key is used to authenticate users when accessing the CRM API.

You can generate an API key in Pancake CRM: Settings → Tools.

The API key may be automatically disabled after a period of inactivity.

How to get api key?
An API key is a token that you provide when making API calls. Include the token in a query parameter called api_key.

Example: ?api_key=123

array[Product Variation]
Product variations (e.g. Red / Size L). On write, this array fully replaces the current variations: existing rows whose custom_id is missing from the new list are deleted, matching rows are updated, and new ones are inserted.
